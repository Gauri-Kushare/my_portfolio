# my_portfolio

Personal creative portfolio of **Gauri Kushare** — Creative Designer & Visual Storyteller.
Crafting scroll-stopping reels, brand identities, graphic designs, cinematics, and responsive websites.

## Tech Stack

- **Framework**: React 19 + TanStack Start / React Router
- **Styling**: Tailwind CSS
- **Bundler & Tooling**: Vite, Vitest, ESLint, Prettier
- **Language**: TypeScript

## Getting Started

### Prerequisites

- Node.js (v18+)
- npm or bun

### Installation

```sh
git clone https://github.com/Gauri-Kushare/my_portfolio.git
cd my_portfolio
npm install
```

### Running Locally

```sh
npm run dev
```

Open [http://localhost:8080](http://localhost:8080) to view the application.

### Building for Production

```sh
npm run build
npm run preview
```

### Testing & Linting

```sh
npm run test
npm run lint
```
